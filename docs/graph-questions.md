Generated by `/graphify` (see `graphify-out/GRAPH_REPORT.md`). 578 nodes, 1415 edges,
26 communities. These are the questions the dependency graph is uniquely positioned to

## Cross-community bridges

- **`MostroService` bridges the API route handlers to the CLI command builder, safe CLI
  runner, and Nostr chat transport** (betweenness 0.061). Everything funnels through this
  one class. Is that the intended seam, or is it a god object that should be split by
  concern (command building vs. process execution vs. chat)?

- **`zod` connects the API route handlers to the CLI command builder and package
  manifest** (betweenness 0.053). Schema validation is the shared contract between the
  HTTP layer and the CLI layer. Worth confirming the schemas are actually shared and not
  duplicated on each side.

- **`vitest` bridges 7 otherwise-separate communities** (betweenness 0.075). Expected for
  a test runner, but it means test setup is the only thing tying several modules together
  — no runtime coupling. Confirms the modules are genuinely independent.
